BEFORE / AFTER SLIDER FOR BEHANCE

1. Replace before.jpg with your BEFORE image.
2. Replace after.jpg with your AFTER image.
3. Keep both images the same dimensions/aspect ratio.
4. Upload all three files (index.html, before.jpg, after.jpg) to a public HTTPS host.
5. Use the public index.html URL as the source for an iframe/embed in Behance.

Recommended:
- JPG or WebP
- Same pixel dimensions for both images
- Avoid very large files

No watermark, logo, or third-party branding is included in this template.
